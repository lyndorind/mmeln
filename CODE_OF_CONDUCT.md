
# Code of Conduct

## Наші принципи

Усі учасники проєкту повинні дотримуватися принципів взаємоповаги, відповідальності та професійної комунікації.

## Очікувана поведінка

- Поважати думку інших учасників.
- Спілкуватися ввічливо та конструктивно.
- Надавати корисні рекомендації.
- Уникати образ та дискримінації.
- Допомагати іншим учасникам проєкту.

## Неприйнятна поведінка

- Образи та погрози.
- Особисті напади.
- Переслідування інших учасників.
- Публікація образливого або дискримінаційного контенту.

## Вирішення конфліктів

У разі порушення правил учасники можуть звернутися до власника репозиторію для вирішення ситуації.
