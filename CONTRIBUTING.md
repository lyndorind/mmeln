
# Contributing Guidelines

Дякуємо за бажання зробити внесок у цей проєкт!

## Як долучитися до проєкту

1. Ознайомтеся з README.md.
2. Перевірте наявні Issues.
3. Оберіть завдання для виконання.
4. Створіть окрему гілку для своїх змін.
5. Внесіть необхідні зміни.
6. Перевірте правильність виконаної роботи.
7. Створіть Pull Request.

## Правила роботи з Git

- Використовуйте зрозумілі назви гілок.
- Створюйте невеликі логічні коміти.
- Пишіть змістовні повідомлення комітів.
- Не вносьте зміни безпосередньо в main.
- Використовуйте Pull Request для об'єднання змін.

## Code Review

Усі зміни повинні пройти перевірку іншим учасником.

Автор Pull Request повинен:
- описати внесені зміни;
- врахувати зауваження рев'ювера;
- виправити виявлені помилки.

## Додаткові рекомендації

Дотримуйтеся єдиного стилю оформлення файлів та документації.
