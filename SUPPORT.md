
# Support

## Отримання допомоги

Якщо у вас виникли питання щодо проєкту, скористайтеся такими можливостями:

1. Перегляньте файл README.md.
2. Ознайомтеся з документацією проєкту.
3. Створіть Issue з описом проблеми.
4. Скористайтеся шаблоном Bug Report для повідомлення про помилку.

## Опис проблеми

Під час звернення вкажіть:
- короткий опис проблеми;
- кроки для її відтворення;
- очікуваний результат;
- фактичний результат.
